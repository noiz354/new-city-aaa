# Core Gameplay Loop

> Corrects gap G-A9 (no gameplay definition). All loops must be playable and testable per slice.

## 1. The 30-second loop (build)

**Observe → Decide → Place → Feedback.** Player reads overlays/RCI/budget (≤3s to spot any problem — pillar #1), picks a tool, drags/paints with live cost+validity ghost, and sees treasury/pop/growth respond within a game-day. Acceptance: place road+plant+R-zone and see first house + pop>0 in <5 min (tutorialized).

## 2. The 10-minute loop (balance)

RCI bars move → zone/work balance shifts → commute/traffic/utilities react → budget ticks monthly → advisors surface the next bottleneck. The game is *never* idle: every milestone (500/1k/5k pop) unlocks a new pressure (power ceiling, congestion, services, pollution). Tuned in [progression-and-balancing](progression-and-balancing.md).

## 3. The session loop (grow → crisis → recover)

Disasters, blackouts, budget crunches, and traffic jams punctuate growth; recovery (bulldoze, rebuild, re-zone) is always affordable and legible. No fail-state that bricks a city without 30+ days of warnings (design rule; bankruptcy included).

## 4. Goals & progression (v1 scope)

- **Tutorial goals:** 5-step checklist → 500 pop.
- **Milestone goals:** population tiers (1k/5k/25k/100k) with unlock toasts + small rewards (e.g., funding efficiency +5% — numbers in tuning).
- **Scenario goals (stretch):** fixed-map challenges (blackout recovery, traffic fix) with par-time + grading.
- **No win-state:** sandbox with scored milestones; "victory" = hitting 100k happy population (balanced target, not a promise).

## 5. Anti-frustration rules (normative)

Every negative state shows **cause + fix + cost** in ≤2 clicks (inspector reason lines, advisor one-click fixes). Nothing punishes experimentation: bulldoze is cheap for empty/rubble, paused placement allowed, autosave always on.
